# pertemuan-02-dasar-python
Ringkasan Program
1. Latihan 1: Biodata Terformat (latihan/01_biodata.py)
 * Deskripsi: Menerima input nama, NIM, kelas, dan tahun lahir pengguna. Mengatur konstanta TAHUN_SEKARANG = 2026 untuk menghitung perkiraan umur, kemudian menampilkan output terformat menggunakan f-string.
 * Catatan Umur Perkiraan: Umur disebut perkiraan karena perhitungan hanya didasarkan pada selisih tahun lahir dan tahun berjalan, tanpa memperhitungkan bulan serta tanggal lahir yang akurat.
2. Latihan 2: Persegi Panjang (latihan/02_persegi_panjang.py)
 * Deskripsi: Menerima input nilai panjang dan lebar dalam tipe data float, kemudian menghitung luas dan keliling persegi panjang.
 * Format Output: Menampilkan nilai luas dan keliling dengan presisi 2 angka di belakang koma (.2f).
3. Latihan 3: Konversi Suhu (latihan/03_konversi_suhu.py)
 * Deskripsi: Menerima masukan suhu dalam derajat Celsius (float), lalu mengonversikannya ke skala Fahrenheit dan Kelvin.

5. Tugas Utama: Kalkulator Koordinat (tugas/kalkulator_koordinat.py)
 * Deskripsi: Menghitung perubahan koordinat, jarak Euclidean, serta titik tengah (midpoint) dari dua titik A(x_1, y_1) dan B(x_2, y_2).
 * Batasan Program: Ditulis secara berurutan (sequential) tanpa menggunakan pernyataan kondisional (if), perulangan (loop), fungsi buatan sendiri (def), maupun pustaka eksternal.
